07

Motion & performance

高频动画只允许 transform 与 opacity；列表按 key 复用、滚动窗口外零节点；曲线是真实弹簧采样的 linear()，不是猜的贝塞尔。

snapk700 · c38 · 0.42 s
softk260 · c26 · 0.62 s
bouncek420 · c22 · 0.73 s
在浏览器里直接跑 Web Animations API，曲线来自 springEasing()。
performance contract
  • 没有对 width / height / top / left 的过渡；进度、指示块与数字用 transform。
  • 环形仪表重绘的是小面积渐变，每秒一次，不进入滚动与逐帧路径。
  • 表格行、toast 与浮层在动画结束或关闭后才从 DOM 移除。
  • 虚拟列表只挂可见窗口，滚出屏幕的行回收到池里复用。
  • prefers-reduced-motion 下所有动画压到 0.01 ms。
measure it yourself

实验室里同时跑 100k 行虚拟列表与 240 条合成器动画，并统计帧间隔与长任务。
